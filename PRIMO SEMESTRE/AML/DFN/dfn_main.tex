 Also called multilayer perceptrons, a feedforward network is a composition of functions
with a certain \textbf{Depth}(number of layers with parameters), \textbf{Width}(number
of units $dI$ in layer $I$). The goal of training is to choose $\theta$ so that $$f(x; \theta) \approx f^*(x)$$
on new inputs, not only on training set. 
\section{Anatomy of a Unit and of a Layer}

For one layer of $m$ units (all read the same $\mathbf{x}$):
\begin{equation}
    \mathbf{h} = g(\mathbf{W}^\top \mathbf{x} + \mathbf{b}), \quad \mathbf{x} \in \mathbb{R}^d, \; \mathbf{W} \in \mathbb{R}^{d \times m}, \; \mathbf{b} \in \mathbb{R}^m
\end{equation}
Column $j$ of $\mathbf{W}$ holds the weights of unit $j$; $g$ is applied to each entry separately.
\newline
$z = \mathbf{w}^\top \mathbf{x} + b$ is the \textbf{pre-activation}: a weighted sum plus bias. $h = g(z)$ is the \textbf{activation}; $g$ is a fixed non-linear function, e.g. the ReLU $g(z) = \max\{0, z\}$.
\newline
As an example with $d = 3$ inputs and $m = 2$ ReLU units:
\begin{align*}
    \mathbf{x} &= (1, 0, 2), \quad \mathbf{W} = \begin{bmatrix} 1 & -1 \\ 0 & 2 \\ 1 & 1 \end{bmatrix}, \quad \mathbf{b} = (0, -1) \\
    \mathbf{z} &= \mathbf{W}^\top \mathbf{x} + \mathbf{b} = (1 + 0 + 2, -1 + 0 + 2) + (0, -1) = (3, 0) \\
    \mathbf{h} &= \max\{0, \mathbf{z}\} = (3, 0)
\end{align*}

For $n$ examples at once: $\mathbf{H} = g(\mathbf{X}\mathbf{W} + \mathbf{1}\mathbf{b}^\top)$; row $i$ of $\mathbf{H}$ is the layer output for example $i$.

\begin{definition}[Saturation]
    A unit is saturated when $|z|$ is so large that its output hardly changes: the slope $g'(z)$ is 
    almost 0
\end{definition}
So when the slope is almost 0 the derivative is 0, is impossible to know from data how much the model
has to change his parameters.

\section{Multilayer Network in Matrix Form}
The forward pass through an $L$-layer network is defined as:
\begin{align*}
    \mathbf{h}^{(0)} &= \mathbf{x} \\
    \mathbf{h}^{(l)} &= g(\mathbf{W}^{(l)\top} \mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}), \quad l = 1, \dots, L - 1 \\
    \hat{\mathbf{y}} &= o(\mathbf{W}^{(L)\top} \mathbf{h}^{(L-1)} + \mathbf{b}^{(L)})
\end{align*}
\newline
The last pre-activation, $\mathbf{z}^{(L)} = \mathbf{W}^{(L)\top} \mathbf{h}^{(L-1)} + \mathbf{b}^{(L)}$, is called the vector of \textbf{logits}; the output function $o$ (identity, sigmoid or softmax) turns it into the prediction.

\begin{definition}[Number of parameters]
Layer $l$ has $d_{l-1} \cdot d_l$ weights and $d_l$ biases:
\begin{equation}
    |\theta| = \sum_{l=1}^{L} (d_{l-1} + 1) d_l
\end{equation}
\end{definition}
Most parameters sit in the first layer. In Fig \ref{tab:mnist_parameters} there is an example of 
the calculus of parameters. The MLP is : $784 \to 256 \to 128 \to 10$. 
Input: $28 \times 28 = 784$ pixels. Output: $10$ classes.

\section{Cost Functions}
The cost function is a mathematical formula that measures the error between the network's predicted
output and the actual target values across a dataset. 
\begin{remark}
    Some sources consider loss and cost to be synonyms, while others consider cost to refer to the 
    entire dataset or a batch of data.
\end{remark}
\subsection{Gradient-Based Learning}
As with linear models, the gradient-based learning is a foundamental training paradigm where model parameters
are iteratively adjusted to minimize a cost function $J(\theta)$ using the \textbf{gradient descent algorithm}: 
\begin{equation}
    \theta \leftarrow \theta - \eta \nabla_{\theta} J
\end{equation}
\noindent where $\eta$ is the learning rate.
\newline
What changes in NN is the fact that the non-linearities make $\mathbf{J}$ \textbf{non-convex}, as shown in 
Fig \ref{fig:gradient_based}, so gradient descent may stop in a minimum that is not the best one, and 
where it stops depends on the starting $\theta$. In conclusion, the initial parameters $\theta$ must be 
\textit{small} in order to start in a non-saturated range, and \textbf{random} because otherwise every
hidden unit would compute the same thing and receive the same update (random values break this symmetry).
\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\linewidth]{immagini/gradient_based.png} 
    \caption{Difference between convex and non-convex}
    \label{fig:gradient_based}
\end{figure}
\noindent
One optimization of the gradient-descent algorithm is the 
\begin{definition}[Minibatch Stochastic Gradient Descent]
The algorithm is repeated until the validation error stops improving. At each step, the algorithm:
\begin{enumerate}
    \item Picks $m$ training examples at random to form a minibatch $\mathcal{B}$.
    \item Averages their gradients to compute $\hat{g} = \frac{1}{m} \sum_{i \in \mathcal{B}} 
    \nabla_{\theta} \ell(f(\mathbf{x}^{(i)}; \theta), y^{(i)})$, where individual gradients 
    are computed via back-propagation.
    \item Takes an optimization step: $\theta \leftarrow \theta - \eta \hat{g}$ using learning rate 
    $\eta$.
\end{enumerate}
\end{definition}
\noindent 
Here, $\hat{g}$ is a noisy but unbiased estimate of the true gradient $\nabla_{\theta} J$. 
A complete pass over all $n$ training examples is called an epoch. The noise of the estimate 
decreases as $1/\sqrt{m}$, with typical batch sizes ranging between $32$ and $512$ 
($32 \le m \le 512$).

\subsection{Maximum Likelihood}
The cost function comes from maximum likelihood, the network defines a 
\textbf{probability distribution} $p_{model}(y|\mathbf{x};\mathbf{\theta})$ over the possible targets. 
An advantage of this approach is that is not necessary to design cost functions for each model.
\begin{definition}[Maximum Likelihood]  
    choose $\theta$ so that the correct answers get high probability. In other words, minimize the average
    negative log-probability:
    \begin{equation}
        J(\theta) = -\frac{1}{n} \sum_{i=1}^{n} \log p_{\text{model}}(y^{(i)} \mid \mathbf{x}^{(i)}; \theta)
    \end{equation}
\end{definition}
An other form of this function is
\begin{equation}
    $$\begin{equation} J(\boldsymbol{\theta}) = -\mathbb{E}_{\mathbf{x},\mathbf{y}\sim\hat{p}_{\text{data}}} \log p_{\text{model}}(\boldsymbol{y} \mid \boldsymbol{x}). \end{equation}$$
\end{equation}
where $\hat{p}_{\text{data}}$ gives probability 1/n to each training pair. This is also called \textbf{Cross-Entropy}.
The negativity helps to avoid the problem of the saturation of the units of the NN.

\subsubsection{Derivation: A Gaussian Output Gives the Squared Error}
A practical application of this principle is choosing a Gaussian output distribution for the network, 
assuming the target is the network output plus Gaussian noise with variance $s^2$:
\begin{equation}
    p_{\text{model}}(y \mid \mathbf{x}) = \mathcal{N}(y; f(\mathbf{x}; \boldsymbol{\theta}), s^2) = \frac{1}{\sqrt{2\pi s^2}} \exp\left(-\frac{(y - f(\mathbf{x}; \boldsymbol{\theta}))^2}{2s^2}\right)
\end{equation}
Taking the negative log-probability yields:
\begin{equation}
    -\log p_{\text{model}}(y \mid \mathbf{x}) = \frac{1}{2s^2} (y - f(\mathbf{x}; \boldsymbol{\theta}))^2 + \frac{1}{2}\log(2\pi s^2)
\end{equation}
Since the last term does not depend on $\boldsymbol{\theta}$, minimizing the average negative 
log-likelihood over the dataset leads directly to the Mean Squared Error cost function:
\begin{equation}
    J(\boldsymbol{\theta}) = \frac{1}{2s^2} \cdot \frac{1}{n} \sum_{i} \left(y^{(i)} - f(\mathbf{x}^{(i)}; \boldsymbol{\theta})\right)^2 + \text{const}
\end{equation}
Thus, under a Gaussian assumption, maximum likelihood is equivalent to minimizing the squared error.
\newline
\textbf{Mean absolute or squared error} often lead to poor results when used with gradient-based 
optimization due to saturation.

\section{Outputs Units}
The choice of cost function is tightly coupled with the choice of output unit. The feedforward network
provides a set of hidden featured defined by $\mathbf{h} = \mathit{f}(\mathbf{x};\mathbf{\theta})$, and
the role of output layer is then to provide some additional transformation from the features to complete 
the task.
\subsection{Linear Units for Gaussian Output Distributions}
Given features $\mathbf{h}$, a layer of linear output units produces a vector 
$\mathbf{\hat{y}} = \mathbf{W}^T\mathbf{h} + \mathbf{b}$. The advantage of a linear unit is that it
never saturates because the slope is always 1. 
They are used to produce the mean of a conditional Gaussian distribution: 
\begin{equation} 
    p(\boldsymbol{y} \mid \boldsymbol{x}) = \mathcal{N}(\boldsymbol{y}; \hat{\boldsymbol{y}}, I). 
\end{equation}
As we saw before, this leads to a \textbf{squared error} for the loss. 
\newline
Furthermore, the network can output two numbers: the mean $\hat{y}$ and a value $v$ for the spread. 
Since the variance must be strictly positive, we set:
\begin{equation}
    s^2 = \zeta(v) = \log(1 + e^v) \quad (\text{always} > 0)
\end{equation}

\subsection{Sigmoid Units for Bernoulli Output Distributions}
Usefull in classification problems with two classes. A Bernoulli distribution is defined by just a 
single number in the interval [0,1]. The NN needs to predict only $P(y=1 | \mathbf{x})$. The sigmoid
is motivated by constructing an unnormalized probability distribution $\tilde{P}(y)$ which does not sums
to 1.
\begin{align*} 
    \log \tilde{P}(y) &= yz, \\ 
    \tilde{P}(y) &= \exp(yz), \\ 
    P(y) &= \frac{\exp(yz)}{\sum_{y'=0}^{1} \exp(y'z)}, \\ 
    P(y) &= \sigma ((2y - 1)z). 
\end{align*}
The variabile z that defines a distribution over binary variables is called \textbf{logit}.
The loss function for maximum likelihood learning of a Bernoulli parametrized by sigmoid is the 
\textbf{Binary Cross-Entropy}:
\begin{align*}
J(\boldsymbol{\theta}) &= -\log P(y \mid \boldsymbol{x}) \\
&= -\log \sigma ((2y - 1)z) \\
&= \zeta ((1 - 2y)z). \quad \text{(softplus)}
\end{align*}
Using the softplus version, in Fig \ref{fig:BCE} we can see that \textit{saturation} occurs only when 
the model already has the right answer. When \textit{z} has the wrong sign, the argument of the softplus
may be simplified to $|\mathit{z}|$ and so the derivative with respect to \textit{z} asymptotes to $sign(z)$, 
meaning that the gradient won't vanish at all.
If we look at the other loss like  the \textbf{Squared Error}, the loss can saturate anytime 
$\sigma(z)$ saturates (The sigmoid activation function saturates to 0 when z becomes very negative 
and saturates to 1 when z becomes very positive)

\subsection{Softmax Units for Multinoulli Output Distributions}
Useful in classification problems with $k$ classes (categorical outputs). The network needs to produce
a vector $\mathbf{\hat{y}}$ representing the probability distribution over $k$ different classes, 
where each element is in $[0,1]$ and the entire vector sums to 1. The softmax function turns logits 
$\mathbf{z} \in \mathbb{R}^k$ into probabilities:
\begin{align*}
\text{softmax}(\mathbf{z})i &= \frac{e^{z_i}}{\sum{j=1}^k e^{z_j}}, \quad i = 1, \ldots, k
\end{align*}
The loss function for the true class $y$ is the negative log-likelihood:
\begin{align*}
\ell &= -\log \text{softmax}(\mathbf{z})y \ = -z_y + \log \sum{j} e^{z_j}.
\end{align*}
The first term pushes the correct logit up, while the second term pushes all logits down 
(the largest one the most). The gradient of the loss with respect to the logits is:
\begin{align*}
\nabla_{\mathbf{z}}\ell = \text{softmax}(\mathbf{z}) - \mathbf{e}_y
\end{align*}
which represents the prediction minus the one-hot target vector.

\subsection{Mixture Density Networks for Multimodal Targets}
Useful for modeling multimodal targets by representing the conditional probability distribution as a weighted sum of $K$ Gaussian bell curves:
\begin{align*}
p(y \mid \mathbf{x}) = \sum_{c=1}^{K} \pi_c(\mathbf{x}) \mathcal{N}(y; \mu_c(\mathbf{x}), s_c^2(\mathbf{x}))
\end{align*}
The network outputs three groups of parameters for each component $c$:
\begin{itemize}
\item \textbf{Weights $\pi_c(\mathbf{x})$}: constrained via a softmax over $K$ (positive and summing to 1).
\item \textbf{Centres $\mu_c(\mathbf{x})$}: produced by standard linear units.
\item \textbf{Spreads $s_c^2(\mathbf{x})$}: constrained to be positive using softplus ($\zeta$) or exponential functions.
\end{itemize}

\section{Hidden units and Activation Functions}
\subsection{Choosing the hidden unit}
Every hidden unit can be described as accepting a vector of inputs $\mathbf{x}$, computing an affine
transformation $\mathbf{z} = \mathbf{W^T}\mathbf{x} + \mathbf{b}$, and then applying an element-wise
non linear function $g(\mathbf{z})$ (\textit{activation function}). 
So units differ only in the activation function, $g$ needs three rules:
\begin{itemize}
    \item non linearity
    \item non zero slope $g^i(\mathbf{z})$
    \item cheap computation
\end{itemize} 
Which $g$ works best is hard to predict, so it is obtained by trial and error.

\subsection{Step Function}
Easiest example of activation function, the slope is 0 everywhere, so the gradient descent gets no
signal.

\subsection{Sigmoid and Hyperbolic Tangent Units}
This two type of units are grouped together because they're functions are closely related: $tanh(z) = 2\sigma(2z) - 1$.
The use of the sigmoid as activation function is discouraged due to the fact that it saturates when 
z is very positive or very negative (Fig \ref{fig:comp_models}). When the sigmoid must be used, the hyperbolic tangent activation 
typically performs bettern than the logistic sigmoid.
