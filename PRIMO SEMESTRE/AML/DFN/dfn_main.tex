 Also called multilayer perceptrons, a feedforward network is a composition of functions
with a certain \textbf{Depth}(number of layers with parameters), \textbf{Width}(number
of units $dI$ in layer $I$). The goal of training is to choose $\theta$ so that $$f(x; \theta) \approx f^*(x)$$
on new inputs, not only on training set. 
\section{Anatomy of a Unit and of a Layer}

For one layer of $m$ units (all read the same $\mathbf{x}$):
\begin{equation}
    \mathbf{h} = g(\mathbf{W}^\top \mathbf{x} + \mathbf{b}), \quad \mathbf{x} \in \mathbb{R}^d, \; \mathbf{W} \in \mathbb{R}^{d \times m}, \; \mathbf{b} \in \mathbb{R}^m
\end{equation}
Column $j$ of $\mathbf{W}$ holds the weights of unit $j$; $g$ is applied to each entry separately.
\newline
$z = \mathbf{w}^\top \mathbf{x} + b$ is the \textbf{pre-activation}: a weighted sum plus bias. $h = g(z)$ is the \textbf{activation}; $g$ is a fixed non-linear function, e.g. the ReLU $g(z) = \max\{0, z\}$.
\newline
As an example with $d = 3$ inputs and $m = 2$ ReLU units:
\begin{align*}
    \mathbf{x} &= (1, 0, 2), \quad \mathbf{W} = \begin{bmatrix} 1 & -1 \\ 0 & 2 \\ 1 & 1 \end{bmatrix}, \quad \mathbf{b} = (0, -1) \\
    \mathbf{z} &= \mathbf{W}^\top \mathbf{x} + \mathbf{b} = (1 + 0 + 2, -1 + 0 + 2) + (0, -1) = (3, 0) \\
    \mathbf{h} &= \max\{0, \mathbf{z}\} = (3, 0)
\end{align*}

For $n$ examples at once: $\mathbf{H} = g(\mathbf{X}\mathbf{W} + \mathbf{1}\mathbf{b}^\top)$; row $i$ of $\mathbf{H}$ is the layer output for example $i$.

\begin{definition}[Saturation]
    A unit is saturated when $|z|$ is so large that its output hardly changes: the slope $g'(z)$ is 
    almost 0
\end{definition}
So when the slope is almost 0 the derivative is 0, is impossible to know from data how much the model
has to change his parameters.

\section{Multilayer Network in Matrix Form}
The forward pass through an $L$-layer network is defined as:
\begin{align*}
    \mathbf{h}^{(0)} &= \mathbf{x} \\
    \mathbf{h}^{(l)} &= g(\mathbf{W}^{(l)\top} \mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}), \quad l = 1, \dots, L - 1 \\
    \hat{\mathbf{y}} &= o(\mathbf{W}^{(L)\top} \mathbf{h}^{(L-1)} + \mathbf{b}^{(L)})
\end{align*}
\newline
The last pre-activation, $\mathbf{z}^{(L)} = \mathbf{W}^{(L)\top} \mathbf{h}^{(L-1)} + \mathbf{b}^{(L)}$, is called the vector of \textbf{logits}; the output function $o$ (identity, sigmoid or softmax) turns it into the prediction.

\begin{definition}[Number of parameters]
Layer $l$ has $d_{l-1} \cdot d_l$ weights and $d_l$ biases:
\begin{equation}
    |\theta| = \sum_{l=1}^{L} (d_{l-1} + 1) d_l
\end{equation}
\end{definition}
Most parameters sit in the first layer. In Fig \ref{tab:mnist_parameters} there is an example of 
the calculus of parameters. The MLP is : $784 \to 256 \to 128 \to 10$. 
Input: $28 \times 28 = 784$ pixels. Output: $10$ classes.

\section{Cost Functions}
The cost function is a mathematical formula that measures the error between the network's predicted
output and the actual target values across a dataset. 
\begin{remark}
    Some sources consider loss and cost to be synonyms, while others consider cost to refer to the 
    entire dataset or a batch of data.
\end{remark}
\subsection{Gradient-Based Learning}
As with linear models, the gradient-based learning is a foundamental training paradigm where model parameters
are iteratively adjusted to minimize a cost function $J(\theta)$ using the \textbf{gradient descent algorithm}: 
\begin{equation}
    \theta \leftarrow \theta - \eta \nabla_{\theta} J
\end{equation}
\noindent where $\eta$ is the learning rate.
\newline
What changes in NN is the fact that the non-linearities make $\mathbf{J}$ \textbf{non-convex}, as shown in 
Fig \ref{fig:gradient_based}, so gradient descent may stop in a minimum that is not the best one, and 
where it stops depends on the starting $\theta$. In conclusion, the initial parameters $\theta$ must be 
\textit{small} in order to start in a non-saturated range, and \textbf{random} because otherwise every
hidden unit would compute the same thing and receive the same update (random values break this symmetry).
\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\linewidth]{immagini/gradient_based.png} 
    \caption{Difference between convex and non-convex}
    \label{fig:gradient_based}
\end{figure}
\noindent
One optimization of the gradient-descent algorithm is the 
\begin{definition}[Minibatch Stochastic Gradient Descent]
The algorithm is repeated until the validation error stops improving. At each step, the algorithm:
\begin{enumerate}
    \item Picks $m$ training examples at random to form a minibatch $\mathcal{B}$.
    \item Averages their gradients to compute $\hat{g} = \frac{1}{m} \sum_{i \in \mathcal{B}} 
    \nabla_{\theta} \ell(f(\mathbf{x}^{(i)}; \theta), y^{(i)})$, where individual gradients 
    are computed via back-propagation.
    \item Takes an optimization step: $\theta \leftarrow \theta - \eta \hat{g}$ using learning rate 
    $\eta$.
\end{enumerate}
\end{definition}
\noindent 
Here, $\hat{g}$ is a noisy but unbiased estimate of the true gradient $\nabla_{\theta} J$. 
A complete pass over all $n$ training examples is called an epoch. The noise of the estimate 
decreases as $1/\sqrt{m}$, with typical batch sizes ranging between $32$ and $512$ 
($32 \le m \le 512$).

\subsection{Maximum Likelihood}
The cost function comes from maximum likelihood, the network defines a 
\textbf{probability distribution} $p_{model}(y|\mathbf{x};\mathbf{\theta})$ over the possible targets. 
An advantage of this approach is that is not necessary to design cost functions for each model.
\begin{definition}[Maximum Likelihood]  
    choose $\theta$ so that the correct answers get high probability. In other words, minimize the average
    negative log-probability:
    \begin{equation}
        J(\theta) = -\frac{1}{n} \sum_{i=1}^{n} \log p_{\text{model}}(y^{(i)} \mid \mathbf{x}^{(i)}; \theta)
    \end{equation}
\end{definition}
An other form of this function is
\begin{equation}
    $$\begin{equation} J(\boldsymbol{\theta}) = -\mathbb{E}_{\mathbf{x},\mathbf{y}\sim\hat{p}_{\text{data}}} \log p_{\text{model}}(\boldsymbol{y} \mid \boldsymbol{x}). \end{equation}$$
\end{equation}
where $\hat{p}_{\text{data}}$ gives probability 1/n to each training pair. This is also called \textbf{Cross-Entropy}.
The negativity helps to avoid the problem of the saturation of the units of the NN.

\subsubsection{Derivation: A Gaussian Output Gives the Squared Error}
A practical application of this principle is choosing a Gaussian output distribution for the network, 
assuming the target is the network output plus Gaussian noise with variance $s^2$:
\begin{equation}
    p_{\text{model}}(y \mid \mathbf{x}) = \mathcal{N}(y; f(\mathbf{x}; \boldsymbol{\theta}), s^2) = \frac{1}{\sqrt{2\pi s^2}} \exp\left(-\frac{(y - f(\mathbf{x}; \boldsymbol{\theta}))^2}{2s^2}\right)
\end{equation}
Taking the negative log-probability yields:
\begin{equation}
    -\log p_{\text{model}}(y \mid \mathbf{x}) = \frac{1}{2s^2} (y - f(\mathbf{x}; \boldsymbol{\theta}))^2 + \frac{1}{2}\log(2\pi s^2)
\end{equation}
Since the last term does not depend on $\boldsymbol{\theta}$, minimizing the average negative 
log-likelihood over the dataset leads directly to the Mean Squared Error cost function:
\begin{equation}
    J(\boldsymbol{\theta}) = \frac{1}{2s^2} \cdot \frac{1}{n} \sum_{i} \left(y^{(i)} - f(\mathbf{x}^{(i)}; \boldsymbol{\theta})\right)^2 + \text{const}
\end{equation}
Thus, under a Gaussian assumption, maximum likelihood is equivalent to minimizing the squared error.
\newline
\textbf{Mean absolute or squared error} often lead to poor results when used with gradient-based 
optimization due to saturation.

\section{Outputs Units}
The choice of cost function is tightly coupled with the choice of output unit. The feedforward network
provides a set of hidden featured defined by $\mathbf{h} = \mathit{f}(\mathbf{x};\mathbf{\theta})$, and
the role of output layer is then to provide some additional transformation from the features to complete 
the task.
\subsection{Linear Units for Gaussian Output Distributions}
Given features $\mathbf{h}$, a layer of linear output units produces a vector 
$\mathbf{\hat{y}} = \mathbf{W}^T\mathbf{h} + \mathbf{b}$. The advantage of a linear unit is that it
never saturates because the slope is always 1. 
They are used to produce the mean of a conditional Gaussian distribution: 
\begin{equation} 
    p(\boldsymbol{y} \mid \boldsymbol{x}) = \mathcal{N}(\boldsymbol{y}; \hat{\boldsymbol{y}}, I). 
\end{equation}
As we saw before, this leads to a \textbf{squared error} for the loss. 
\newline
Furthermore, the network can output two numbers: the mean $\hat{y}$ and a value $v$ for the spread. 
Since the variance must be strictly positive, we set:
\begin{equation}
    s^2 = \zeta(v) = \log(1 + e^v) \quad (\text{always} > 0)
\end{equation}

\subsection{Sigmoid Units for Bernoulli Output Distributions}
Usefull in classification problems with two classes. A Bernoulli distribution is defined by just a 
single number in the interval [0,1]. The NN needs to predict only $P(y=1 | \mathbf{x})$. The sigmoid
is motivated by constructing an unnormalized probability distribution $\tilde{P}(y)$ which does not sums
to 1.
\begin{align*} 
    \log \tilde{P}(y) &= yz, \\ 
    \tilde{P}(y) &= \exp(yz), \\ 
    P(y) &= \frac{\exp(yz)}{\sum_{y'=0}^{1} \exp(y'z)}, \\ 
    P(y) &= \sigma ((2y - 1)z). 
\end{align*}
The variabile z that defines a distribution over binary variables is called \textbf{logit}.
The loss function for maximum likelihood learning of a Bernoulli parametrized by sigmoid is the 
\textbf{Binary Cross-Entropy}:
\begin{align*}
J(\boldsymbol{\theta}) &= -\log P(y \mid \boldsymbol{x}) \\
&= -\log \sigma ((2y - 1)z) \\
&= \zeta ((1 - 2y)z). \quad \text{(softplus)}
\end{align*}
Using the softplus version, in Fig \ref{fig:BCE} we can see that \textit{saturation} occurs only when 
the model already has the right answer. When \textit{z} has the wrong sign, the argument of the softplus
may be simplified to $|\mathit{z}|$ and so the derivative with respect to \textit{z} asymptotes to $sign(z)$, 
meaning that the gradient won't vanish at all.
If we look at the other loss like  the \textbf{Squared Error}, the loss can saturate anytime 
$\sigma(z)$ saturates (The sigmoid activation function saturates to 0 when z becomes very negative 
and saturates to 1 when z becomes very positive)

\subsection{Softmax Units for Multinoulli Output Distributions}
Useful in classification problems with $k$ classes (categorical outputs). The network needs to produce
a vector $\mathbf{\hat{y}}$ representing the probability distribution over $k$ different classes, 
where each element is in $[0,1]$ and the entire vector sums to 1. The softmax function turns logits 
$\mathbf{z} \in \mathbb{R}^k$ into probabilities:
\begin{align*}
\text{softmax}(\mathbf{z})i &= \frac{e^{z_i}}{\sum{j=1}^k e^{z_j}}, \quad i = 1, \ldots, k
\end{align*}
The loss function for the true class $y$ is the negative log-likelihood:
\begin{align*}
\ell &= -\log \text{softmax}(\mathbf{z})y \ = -z_y + \log \sum{j} e^{z_j}.
\end{align*}
The first term pushes the correct logit up, while the second term pushes all logits down 
(the largest one the most). The gradient of the loss with respect to the logits is:
\begin{align*}
\nabla_{\mathbf{z}}\ell = \text{softmax}(\mathbf{z}) - \mathbf{e}_y
\end{align*}
which represents the prediction minus the one-hot target vector.

\subsection{Mixture Density Networks for Multimodal Targets}
Useful for modeling multimodal targets by representing the conditional probability distribution as a weighted sum of $K$ Gaussian bell curves:
\begin{align*}
p(y \mid \mathbf{x}) = \sum_{c=1}^{K} \pi_c(\mathbf{x}) \mathcal{N}(y; \mu_c(\mathbf{x}), s_c^2(\mathbf{x}))
\end{align*}
The network outputs three groups of parameters for each component $c$:
\begin{itemize}
\item \textbf{Weights $\pi_c(\mathbf{x})$}: constrained via a softmax over $K$ (positive and summing to 1).
\item \textbf{Centres $\mu_c(\mathbf{x})$}: produced by standard linear units.
\item \textbf{Spreads $s_c^2(\mathbf{x})$}: constrained to be positive using softplus ($\zeta$) or exponential functions.
\end{itemize}

\section{Hidden units and Activation Functions}
\subsection{Choosing the hidden unit}
Every hidden unit can be described as accepting a vector of inputs $\mathbf{x}$, computing an affine
transformation $\mathbf{z} = \mathbf{W^T}\mathbf{x} + \mathbf{b}$, and then applying an element-wise
non linear function $g(\mathbf{z})$ (\textit{activation function}). 
So units differ only in the activation function, $g$ needs three rules:
\begin{itemize}
    \item non linearity
    \item non zero slope $g^i(\mathbf{z})$
    \item cheap computation
\end{itemize} 
Which $g$ works best is hard to predict, so it is obtained by trial and error.

\subsection{Step Function}
Easiest example of activation function, the slope is 0 everywhere, so the gradient descent gets no
signal.

\subsection{Rectified Linear Units And Their Generalizations}
Those units use the activation function $g(z) = max(0, z)$. Easy to optimize because they
are so similar to linear units with the only difference that ReLU outputs zero across half
its domain. When active, the unit passes the error signal back \textbf{unchanged} (slope 1), 
no saturation on the positive side. 
\newline
ReLU isn't differentiable\footnote{a function is differentiable if can be locally 
approximated by a linear function} at 0, so the software return 1 or 0, in any case 
most of the time when we work with float types it's rare to have a perfect 0 value. 
\newline
When initializing the parameters, it can be a good practice to set all elements of 
$\mathbf{b}$ to a small positive value (i.e. 0.1) in order to avoid the dead units. 
Infact if z < 0 for every training example, the unit always outputs 0, its slope 
is always 0, and its weights never change again.
There are some \textbf{generalization} that are based on using a nonzero slope $\alpha_i$
when $z_i$ < 0: 
\begin{equation}
    h_i = g(z, \alpha)_i\ = max(0, z_i) + \alpha_imin(0, z_i)   
\end{equation}
and they are:
\begin{itemize}
    \item Absolute value: $\alpha = -1$ and so $g(z) = |z|$, used for object recognition from images
    \item Leaky ReLU: $\alpha = 0,01$
    \item Parametric ReLU $\alpha$ is learned, the data choose the leak.
\end{itemize}
One further generalization is the \textbf{Maxout units}, instead of applying an element-wise
function $g(z)$, maxout units divide $\mathbf{z}$ into groups of $k$ values. A maxout unit
can learn a piecewise linear, convex function with up to k pieces. It of course has a k
times more weights per unit.
\begin{equation}
    h = \max_{j=1,\dots,k} \left( \boldsymbol{w}_j^\top \boldsymbol{x} + b_j \right)
\end{equation}

\subsubsection{Activations in Modern Networks}
Modern networks use a variation of the ReLU that try to minimize the number of dead units,
in Fig \ref{fig:modern_activations} there is a summarize of the 3 variations.
\newline
The difference between ReLU and GELU is the fact that GELU multiplies z by a soft gate
while ReLU uses a hard gate. Thanks to this GELU gains fewer dead units.
\newline
Infact \textbf{ReLU} is defined as:
\begin{equation}
\text{ReLU}(z) = z \cdot \mathbb{1}[z > 0]
\end{equation}
and \textbf{GELU} is defined as:
\begin{equation}
\text{GELU}(z) = z \Phi(z), \quad \Phi(z) = P(Z \leq z), \quad Z \sim \mathcal{N}(0, 1)
\end{equation}
\textbf{SwiGLU} (Swish-Gated LU) the idea is similar as GELU, with $\sigma$ in place 
of $\Phi$: $\text{SiLU}(z) = z \sigma(z)$. In GELU and SiLU the gate depends on $z$ 
\textbf{itself}. In SwiGLU a \textbf{second linear map} of the input computes it:
\begin{equation}
\boldsymbol{h} = \underbrace{\left( \boldsymbol{W}_a^\top \boldsymbol{x} \right)}_{\text{content }\boldsymbol{a}} \odot \underbrace{\text{SiLU}\left( \boldsymbol{W}_b^\top \boldsymbol{x} \right)}_{\text{gate }\boldsymbol{s}}, \qquad \hat{\boldsymbol{y}} = \boldsymbol{W}_2^\top \boldsymbol{h}
\end{equation}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\linewidth]{immagini/relu.png} 
    \caption{Comparison between activation functions}
    \label{fig:modern_activations}
\end{figure}

In conclusion, when using ReLU or a variant, the rule is to pick random and small 
weights and small biases (i. e. 0,01). It is important not to start with weights equal
to 0 because other wise the gradient would \textbf{vanish}. It is important not to 
pick a too large weights neither because otherwise the gradient would \textbf{explodes}.
THe idea is to choose them from a set $Var(w)$ ruled by a variance value, there are two main 
formulations:
\begin{itemize}
    \item Glorot: $\frac{2}{n_{in} + n_{out}}$
    \item He: $\frac{2}{n_{in}}$
\end{itemize}  
where n is the number of inputs per unit.

\section{Architecture Design}
The architecture of a network is defined by the number of the units the it has and how they are 
connected to each other. A group of units that works in linear combinations is called \textbf{layer}, 
most of architecture arrange these layers in a chain structure in which each layer is a function of the
layer that preceded it. 
\newline 
In this structure, the first layer is given by $\mathbf{h}^{(1)} = g^{(1)} \left( \mathbf{W}^{(1)\top}
\mathbf{x} + \mathbf{b}^{(1)} \right)$ and the second layer is given by $\mathbf{h}^{(2)} = g^{(2)} 
\left( \mathbf{W}^{(2)\top} \mathbf{h}^{(1)} + \mathbf{b}^{(2)} \right)$ and so on. This mean that in 
this chain-based architectures, the main architectural considerations are choosing the depth of the 
network and the width of each layer. Generally speaking, one hidden layer is sufficient to fit the
training set, but it isn't as optimized as a deeper network. The ideal network architecture for a task
must be found via experimentation with the validation set error.

\subsection{Universal Approximation Properties and Depth}
Feedforward networks with hidden layers provide a universal approximation framework:
\begin{theorem}[Universal Approximation Theorem]
For any continuous $f$ on a closed and bounded region of $\mathbb{R}^d$ and any tolerance 
$\varepsilon > 0$, there is a network with \textbf{one hidden layer} of $N$ units and a linear output,
$$\hat{f}(\boldsymbol{x}) = \sum_{i=1}^{N} v_i \, g\left(\boldsymbol{w}_i^\top \boldsymbol{x} + 
b_i\right),$$ with $|f(\boldsymbol{x}) - \hat{f}(\boldsymbol{x})| < \varepsilon$ for every 
$\boldsymbol{x}$ in the region. Valid for sigmoid, tanh, ReLU: any continuous $g$ that is not a polynomial.
\end{theorem}
In other words, one hidden layer can represent any continuous function as accurately as we want.
\newline
This theorem means that regardless of what function we are trying to learn, we know that a large MLP 
will be able to represent it. We are not guaranteed that the training algorithm will be able to learn
that function.

\subsubsection{Sigmoid Application of Universal Approximation Theorem}
A hidden unit with one input computes $\sigma(wx + b) = \sigma(k(x - a))$ where $k = w$ is the 
\textbf{weight} that sets the steepness and $ a = -\frac{b}{w}$ is the bias that describe where the 
step happens.
\newline
In Fig \ref{fig:step_sigmoid} it is shown that a large weight turns the sigmoid into a \textbf{step}.

\begin{enumerate}

    \item Put a bump of height $h_i = f(interval\ centre)\ \forall\ interval\ i$
    \item Add the bumps
\end{enumerate}
So formally in the network:
\begin{equation}

\end{equation}
As we can see steps are shared within the bumps(Fig \ref{fig:curve_sigmoid}), so the sum needs only $N - 1$ sigmoid unit plus 
a bias.

\subsubsection{ReLU Application of Universal Approximation Theorem}
The foundational principle for function approximation with ReLU remains equivalent to the sigmoid 
case: decomposing the input space and summing elementary local building blocks to construct the 
target function. However, the geometric properties of these building blocks differ due to the 
piecewise linear nature of this function. Unlike the sigmoid function, which generates smooth steps and 
bell-shaped curves, a single hidden unit with ReLU computes a linear \textbf{ramp}:
\begin{equation}
h(x) = \max\left(0, w x + b\right)
\end{equation}
where the weight $w$ controls the slope and the bias $b$ determines the activation threshold (the elbow point).
\begin{itemize}
\item Subtracting two shifted ReLU units with opposite slopes yields a \textbf{triangular bump} (tent function).
\item Summing these triangular bumps creates a piecewise linear spline that fits any continuous 1D target function.
\end{itemize}

    \caption{Approximation with ReLU}
    \label{fig:relu_curve}
\end{figure}

\subsubsection{Two-dimensional approximation}
In one dimension, a sigmoid unit produces a smooth step. In two dimensions, the same unit
\[
    h(\mathbf{x})=\sigma(w_1x_1+w_2x_2+b)=\sigma(\mathbf{w}^\top\mathbf{x}+b),
    \qquad \sigma(z)=\frac{1}{1+e^{-z}},
\]
with input $\mathbf{x}=(x_1,x_2)$, can be seen as that step stretched along the new dimension. 
Plotted over the $(x_1,x_2)$ plane, it gives a surface that is low on one side of a line and high on
 the other. We call this surface a \textbf{wall}.
The unit depends on $\mathbf{x}$ only through the scalar $\mathbf{w}^\top\mathbf{x}+b$, so $h$ is 
constant on every line
\[
    w_1x_1+w_2x_2+b=c .
\]
Indeed, if we move by a small displacement $(\Delta x_1,\Delta x_2)$ along such a line, the quantity 
$\mathbf{w}^\top\mathbf{x}+b$ does not change, hence $\mathbf{w}^\top\Delta\mathbf{x}=0$. This means 
that \emph{the level lines are perpendicular to $\mathbf{w}$}, and $\mathbf{w}$ points in the 
direction in which $h$ grows fastest, i.e.\ the direction in which the wall rises.
The parameters play the following roles:
\begin{itemize}
    \item The \textbf{direction} of $\mathbf{w}$ sets the orientation of the wall. For example, $\mathbf{w}=(1,0)$ gives vertical level lines, $\mathbf{w}=(0,1)$ gives horizontal ones, and $\mathbf{w}=(1,1)$ gives diagonal lines $x_1+x_2=\text{const}$.
    \item The \textbf{norm} $\|\mathbf{w}\|$ sets the steepness: large weights give a nearly vertical transition, small weights a gentle one.
    \item The \textbf{bias} $b$ translates the wall without changing its orientation. The transition, where $h=1/2$, lies on the line $\mathbf{w}^\top\mathbf{x}+b=0$.
\end{itemize}
The problem with a wall is that it is infinitely long along the direction in which $h$ does not 
change, so it cannot be a localized bump. To enclose a bounded region we need to combine several 
walls with \emph{different orientations}: the result is a \textbf{tower}.
A concrete construction for the square $[-1,1]^2$ uses four hidden units with steepness $k$:
\[
    s(\mathbf{x})=\sigma\big(k(x_1+1)\big)+\sigma\big(-k(x_1-1)\big)+\sigma\big(k(x_2+1)\big)+\sigma\big(-k(x_2-1)\big).
\]
For large $k$, $s\approx 4$ inside the square, $s\approx 3$ outside it but beyond a single side, and $s\approx 2$ in the outer corner regions. Summing the walls alone therefore does not give a uniform plateau. Adding an output unit that thresholds the sum,
\[
    T(\mathbf{x})=\sigma\big(k\,(s(\mathbf{x})-3.5)\big),
\]
yields $T\approx 1$ inside the square and $T\approx 0$ elsewhere, which is a tower. This construction
uses five units arranged in two layers, since the second nonlinearity is what produces the flat top. 
With a single hidden layer and a linear readout, a tower can still be approximated, but with more 
units, for example by combining wall pairs in various positions.
This approach has a price. To approximate an arbitrary function, we can cover the input space with a 
grid, cutting each of the $d$ axes into $n$ pieces and placing one tower per cell. This requires 
$n^d$ towers, so the number of units grows exponentially with the input dimension.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.99\linewidth]{immagini/wall_tower_curve.png}
    \caption{3d surface plot}
    \label{fig:wall_tower_curve}
\end{figure}

\subsection{Deep vs Shallow}
We said that a network with a single layer is sufficient to represent any function, but the layer may 
be infeasibly large. In many circumstances, using deeper models can reduce the number of units 
required to represent the desired function and can reduce the amount of generalization error.
\begin{definition}[The Exponential Capacity of Depth]
A ReLU network with $d$ inputs, $L$ layers of $q$ units can split the input space into about
$$\left(\frac{q}{d}\right)^{d(L-1)} q^d$$
linear regions: exponential in the depth $L$.
\end{definition}
For example in Figure \ref{fig:composition_relu} we see that with $t(x) = 2max{0,x} - 4max{0,x - \frac{1}{2}}$
two ReLUs make a tent on [0,1], $t(t(x))$ \textbf{folds} the tent into two tents and so on.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\linewidth]{immagini/composition_relu.png}
    \caption{Exponential advange of deeper rectifier networks}
    \label{fig:composition_relu}
\end{figure}
\noindent
Figure \ref{fig:space_fold} shows a geometric representation of this concept, an absolute value unit 
$g(z) = |z|$ gives the same output for a point and its mirror image across the line z = 0, it folds 
the plane like a sheet of paper. Whatever the next layers compute is repeated on both halves; 
each further layer folds again: 2, 4, 8, . . . copies.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\linewidth]{immagini/space_fold.png}
    \caption{Exponential advantage of deeper rectifier networks}
    \label{fig:space_fold}
\end{figure}
\noindent
A deep model assumes that the target is a composition of simpler functions or has a repeated structure,
using the fold concept, depth can be exponentially more efficient.
